Verificación Pública de Autenticidad

Ingrese el código de verificación del certificado (formato: EA-XXXX-XXXX-XXXX-XXXX) para comprobar si fue emitido válidamente por la plataforma EcoAula.

✅ Certificado Auténtico y Válido

El código EA-XXXX corresponde a un certificado legalmente emitido y registrado en la base de datos de EcoAula.

Por protección de datos sensibles y normatividad de privacidad (ADR-06), el sistema no divulga públicamente la identidad del aprendiz.

❌ Certificado No Válido o Inexistente

No se encontró ningún registro activo para el código EA-XXXX.

Verifique que haya copiado todos los caracteres y guiones exactamente como figuran en el documento original.

API REST para integración externa

Los sistemas externos pueden verificar certificados sin sesión mediante la ruta pública:

GET /api/v1/certificados/{codigo}/verificacion

Respuesta: {"valido": true} o {"valido": false}.
